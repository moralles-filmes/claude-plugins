# padrao-saas

Norma dos projetos SaaS (arquitetura, segurança, multi-tenancy, controle de acesso por empresa/filial/módulo, banco, integrações, API pública, ciclo de vida da empresa, testes, operação) e as skills que a aplicam:

- `/padrao-saas:aplicar` — instala, audita ou atualiza o padrão num projeto;
- `/padrao-saas:novo-modulo` — cria, amplia ou remove um módulo com Definition of Done.

Guia completo: **[LEIA-ME.md](./LEIA-ME.md)**. Primeira mensagem em cada projeto: **[PROMPT_INICIAL.md](./PROMPT_INICIAL.md)**.
